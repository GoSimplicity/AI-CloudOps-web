# 本地演示 API

所有合成资源均带演示标识，仅供本机开发浏览。不会连接 Kubernetes、模型、云厂商、Prometheus、SSH 或通知服务。演示数据不代表真实资源、健康度、模型预测准确率或操作执行结果。

在 Web 仓库根目录启动：

```sh
node scripts/demo/server.mjs
pnpm --filter @vben/web-antd exec vite --mode demo --host 127.0.0.1 --port 18080 --strictPort
```

演示 API 仅监听 `127.0.0.1:18089`；登录、权限及允许的本地业务读取转发到固定 `127.0.0.1:8889`。管理员使用本地 Go 服务配置的账号密码，本脚本不创建或保存凭据。不要使用带 `--mode development` 的普通 `dev` 脚本启动演示。普通 dev/prod 代理逻辑不变；演示代理仅在 Vite `serve` 的 `demo` mode 开启。

| 范围 | 行为 |
| --- | --- |
| 登录、用户、RBAC、CMDB 本地节点与主机 CRUD | 仅静态白名单内路径转发本机 Go |
| 工单、告警、Cron | 允许白名单内本地数据库读取；变更和执行暂拒绝 |
| 云账号、地域、云主机、托管资源与操作历史 | 无凭据的只读合成数据，账号禁用；动态地域查询、同步及变更拒绝 |
| K8s 集群、命名空间、节点、工作负载、网络、存储、配置、权限资源 | 合成列表、详情、分页、搜索、YAML、事件及版本历史 |
| Pod 日志 | 有结束标记的本地 SSE 演示文本 |
| 系统首页 | 合成主机指标采样；不是本机或线上监控 |
| 站内收件箱 | 4 条无真实工单关联的合成消息；列表/未读与内存标记已读，重启重置，删除拒绝 |
| 助手与知识文档 | 进程内会话、固定模板回答与文档；重启清空 |
| RCA | 合成指标、日志、事件及分析；缓存不可用明确展示 |
| 预测与回测 | 合成曲线；本地计算输入回测误差，不提供真实准确率或覆盖率 |
| 自动修复 | 合成阻止结果，`executed_actions=[]`；不能审批执行 |
| SSH、WS 终端、云 SDK、通知投递、Cron 执行、未登记 API | 明确拒绝，不回退任何上游 |

`local-go-routes.json` 是实际静态转发白名单。API 新增不会自动加入此文件。生成路由覆盖报告（不发起网络请求）：

```sh
node scripts/demo/write-inventory.mjs
```

`route-inventory.json` 标明可静态提取 API 的模拟、本地 Go 和拒绝分类。变量拼装 URL、SSE 和 WS 不会被这个清单完整枚举，SSE/WS 的独立回归负责相应边界。清单不是全模块验收证明。

验证：

```sh
pnpm test:demo
pnpm exec eslint scripts/demo/*.mjs
```

测试只使用随机回环端口与假的 Go 接收端；合成及拒绝路径断言上游调用为零。服务不记录请求 body、令牌或凭据。默认只支持 JSON 请求；上传文件等未实现接口会明确失败。全模块浏览器验收由本地集成阶段执行。

## 本轮集成验收

- 本地Go真实鉴权、88条幂等业务样例与独立演示库；未启用Cron、外部凭据或通知队列。
- 对57个静态叶路由逐页打开巡检，无JavaScript页面异常；一次401为令牌刷新过程，随后页面正常，不作为接口失败隐藏。动态终端路由及真实执行操作不在通过范围。
- 手工输入四项指标可显示24小时合成预测曲线；RCA目录响应与真实解析一致，降级示例可展示且明确未连接模型/未实际采集。
- 收件箱4条内存样例，标记已读不写真实账本；服务重启重置。
- 模式验证包含build、production、preview与缺失环境；`preview --mode demo`不能启用代理。两条无真实handler的legacy写请求明确拒绝。
- `pnpm test:demo`当前27项通过并接入Verify CI。475条可静态提取声明中112条白名单转本地Go、125条合成、238条明确拒绝，含重复声明；不代表475个独立接口全部实现。

入口只用于本地演示，不提供fresh安装或生产上线。Go已准备环境的恢复说明见相邻后端仓库`docs/demo-local.md`；凭据只保存在本机私有运行目录，不能提交。
