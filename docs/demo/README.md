# 本地演示导览

当前入口：`http://127.0.0.1:18080/`。顶部“本地演示”表示页面包含合成数据，外部执行被关闭；这不是生产环境。

本机管理员为 `admin`，密码只保存在私有 `/tmp/cloudops-demo-20261103/login.env`。不要复制到仓库、日志或共享文档。Go后端8889、演示API18089、数据库13306及Redis16379均为本机开发依赖。

## 从这些页面开始

| 页面 | 可以查看的内容 |
| --- | --- |
| 服务树 / 本地资源 | 4个树节点、9台多环境主机及绑定关系；无SSH凭据 |
| 云账户 / 云资源 | 6厂商合成账户、ECS与托管资源；没有真实云密钥 |
| Prometheus | 池、采集任务、规则、录制规则和恢复事件；任务均禁用 |
| 值班组 | 3个示例组与成员；查看组详情及排班入口 |
| 工单实例 | 6种状态、时间线与评论；流程和模板禁用 |
| Kubernetes | 1个合成集群、命名空间、节点、3个Pod及多类资源；可看详情/YAML/演示日志 |
| 系统管理 | 用户、角色、接口目录和6条被动审计样例；示例用户不能登录，未授予额外API权限 |
| 站内消息 | 4条进程内样例，已读只更新内存，重启重置；真实投递账本为空 |
| 预测看板 | 输入QPS1200、CPU46、内存63、磁盘51，再点“开始预测”，查看合成24小时曲线 |
| 根因分析 | 默认命名空间发起分析，查看明确标识的降级样例；没有真实采集或模型分析 |

设计器、新会话、需选择组/资源的页面不会自动执行任务。部分页面需要先选择集群、命名空间或值班组；空结果不等同于服务故障。

## 操作边界

本机用户/角色与服务树、主机的明确白名单CRUD可写入独立演示库。云同步、SSH、集群执行、Cron触发、通知投递及未实现写入均拒绝，不会返回伪造成功。不要将真实凭据或线上地址填入演示环境。

Go种子数据按专用前缀和marker幂等追加，不覆盖已有样例修改；当前88条业务记录。云/K8s/AI合成数据及Inbox由独立进程生成，不能拿来证明真实资源健康、模型质量或操作成功。

启动与专项测试见 [演示API说明](../../scripts/demo/README.md)。已准备Go环境的恢复工具位于相邻后端仓库 `scripts/demo-local.py`，其文档明确不支持fresh安装和未执行的停服恢复边界。服务保持运行供浏览，普通开发、构建和生产预览不自动启用demo代理。
