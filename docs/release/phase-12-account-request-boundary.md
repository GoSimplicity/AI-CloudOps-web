# 第十二阶段：页面缓存与请求账户边界

日期：2026-10-23

## 变更日志

- 页面、iframe 与 KeepAlive 容器按稳定用户 UID 隔离；UID 或令牌缺失立即卸载业务内容，退出后同 UID 重新登录也销毁前一会话缓存。外层登录过期弹窗保留，普通令牌刷新不重建当前页面
- 应用请求客户端在同步调用入口捕获 UID、登录代际与认证状态；Axios 拦截器读取凭证、处理响应或重放请求之前均验证归属，旧响应以不带私有响应体和认证配置的取消错误结束
- 刷新任务按账户代际分组，新账户无需等待旧刷新；旧 401 不刷新、不重放旧写请求、不清除新凭证，旧刷新结果不能写回新账户。退出后的未认证请求不能用遗留 refreshToken 恢复旧登录
- 新登录开始即清理前账户令牌；资料加载允许同 UID 正常轮换令牌，保持退出、登录、资料乱序保护

## 验证

先以真实 Vue Router/KeepAlive 与应用 RequestClient + Axios adapter 建立红例，初始七项失败；另单独复现同一 tick 旧账户写请求被新凭证发送的问题，再把归属捕获前移同步请求入口。最终四个专项文件 26 项通过，覆盖两个 UID、同 UID 重登、退出、迟到成功/401、旧刷新成功/失败、新账户独立刷新、无认证状态与初始化 UID 收敛

冻结的完整工作树通过应用 TypeScript、65 个文件 / 494 项单元测试与 11 项生产构建任务。真实 Chrome 通过服务端登录、资料 UID、助手旧缓存拒绝和退出清空（2.1 秒）；跨 UID 与并发完成顺序使用真实请求 adapter/组件回归验证，没有把网络替身当作第二账户的真实服务端集成
