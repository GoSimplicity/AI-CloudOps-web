# 第三阶段：工单列表与移动端共享布局

日期：2026-10-23

## 变更日志

- 流程、模板、表单管理三个真实业务页面使用 `OpsPage`，复用标题、主操作、筛选、摘要与表格区域
- 保留真实查询、创建、编辑、预览、删除及流程设计表单；查询失败时清除失效记录、显示可见错误，并提供重试
- 分页状态数量标注“本页”，模板“本页本月新增”的月初时间归零，避免遗漏月初当天的记录
- 系统与工单列表在 390px 使用两列紧凑摘要，系统卡片约 84px，高度不超过 100px，保留首屏列表空间
- 640px 以下隐藏悬浮设置与助手浮窗，完整助手仍可从菜单访问；搜索与重置按钮、表格头部加入真实命中检测和点击验收
- 移动端取消表格固定列定位，保留横向滚动，修复右侧操作列覆盖首列的问题
- 统一表格区域的内边距，去掉表格外层卡片的重复边界，移动筛选控件占满可用宽度
- GitHub Actions 增加按 workflow/ref 分组的并发控制，后续推送取消旧提交尚未完成的检查
