# 第八阶段：AI 助手账户隔离

日期：2026-10-23

## 变更日志

- 修正认证资料映射：后端 profile 的稳定用户 ID 为 id，统一映射为 userStore.userId，缓存不依赖名称、邮箱或客户端输入
- 助手聊天、会话列表使用 UID 作用域的版本化存储键和 owner envelope；未登录不能读写敏感缓存
- 删除旧 aiAssistantChatState、aiAssistantSessions、assistant-session-history 无归属键，不把历史记录自动认领给当前账户；已有新版本账户缓存分别保留
- 悬浮助手、独立问答与会话管理页面在换账户/退出时同步清空内存、输入、SID、详情和状态，并中止可取消请求
- 请求代际阻止旧账户及取消前的响应、异常、模拟逐字呈现或 finally 回调影响当前账户；退出开始即清空用户资料，迟到 profile/登录/退出响应不能覆盖新登录
- 会话查询及问答遇到 403/404 清除失效 SID 和对应内容；会话管理删除失效历史，下次提问允许新建会话
- 独立问答按真实 role/content 结构发送当前账户历史，不发送错误的角色名称动态键
- 共享请求客户端保留 HTTP 错误状态及原有业务字段，供 403/404 分类使用；安全元数据不带 Axios 请求配置或认证头

## 验证口径

新增 25 个缓存、认证及真实 Vue 组件回归：两 UID 切换、退出、旧无归属键拒绝、缓存 owner 校验、退出/登录/profile 完成顺序、请求乱序与取消、403/404 清理及重新建会话

真实 Chrome 使用隔离环境账号完成登录、旧缓存不显示、新缓存归属 UID、会话管理空历史及退出后界面清空；配套 owner 隔离版 AIOps b2b30ae 对未知 SID 实际返回 404，页面清除旧消息与 SID、恢复输入并正常退出，共 2 例通过，未发起新模型请求。新增真实 axios adapter 到组件的 403/404 回归，避免只模拟错误对象遗漏共享请求层的状态丢失。后端跨账户所有权验证仍由配套服务测试负责
