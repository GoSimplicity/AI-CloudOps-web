# 助手会话恢复

问答页和浮动助手先创建空会话，再使用稳定 turn_id 发送问题。网络中断后先查询所属会话，只有服务端确认该请求完成，才使用原 ID 读取保存结果；running/unknown 不重新执行。刷新仅凭当前用户的会话 ID 从服务端读取历史，浏览器不保存问答正文。权限或身份变化使旧响应失效，读取故障保留查询恢复入口。

会话详情展示持久状态与历史。创建会话、查询历史和发送问题分别需要对应 API 权限；未知状态需人工核对，清空本地索引不会取消服务端执行。

本阶段会话相关 27 项组件测试、全应用类型检查通过。后端持久化、跨进程及 Redis 故障验收见 AIOps 仓库合同。真实模型及生产服务未访问。
