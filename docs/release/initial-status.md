# 创建时明确初始状态

定时任务和云账户的创建表单均可选择初始启用或停用，默认仍为启用（1）。停用（2）只保存配置，不调度任务或自动发起云动作；后续启用继续使用原有独立操作与权限。编辑已有记录不通过创建字段改变状态。

API的创建status为可选1/2，省略兼容原客户端。该功能要求配套后端已实现初始状态字段；新表单不能与忽略status的旧后端混合部署。使用三仓固定组合验收与候选清单。

HTTP执行地址的创建/编辑共用HTTP/HTTPS语法校验，合法单数字端口不再被旧URL正则误拒绝；非HTTP协议、空host、非法端口、空格/控制符和反斜杠均拒绝，校验不访问该地址。
