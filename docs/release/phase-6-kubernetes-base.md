# 第六阶段：Kubernetes 集群与命名空间

日期：2026-10-23

## 变更日志

- 根据真实路由迁移集群、命名空间页面至 `OpsPage`，统一页头、主操作、筛选、错误和表格区域，移除重复刷新入口
- 保留集群接入/编辑/详情、命名空间创建/标签/详情及删除等业务能力；本阶段真实环境只查询和取消表单
- 集群和资源查询失败清空旧结果、分页与选择，显示错误与重试；未选择集群时明确空态并禁用创建/刷新
- 通过请求序号隔离异步查询，旧集群的迟到响应不能覆盖新集群，清空选择后也不会恢复旧资源
- 集群详情加载失败时关闭编辑，避免提交不完整的连接配置
- 移除日常集群切换的干扰提示，长集群名使用省略及完整标题，装饰图标不进入按钮读屏名称
- 移动端收起全局搜索和全屏等次要工具，保留账户菜单完整边界，避免顶部操作挤出屏幕
- 菜单使用清晰的 Kubernetes、集群和命名空间名称，保留路由标识

Chrome 使用隔离后端真实 kind 集群，只读取指定测试资源：集群列表、命名空间列表、清空和恢复选择、创建表单取消、390px 操作与筛选控件命中、表头无覆盖及无页面横向溢出。没有使用网络 mock 伪装 Kubernetes 资源，也没有删除集群或测试命名空间
