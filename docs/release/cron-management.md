# 定时任务页面阶段变更

页面使用 OpsPage 的标题、操作与筛选插槽，保留原有 composable 负责数据和业务操作。移除模块内重复标题、彩色按钮、投影和位移样式，表格、表单、结果与窄屏布局使用控制台语义 token。表格取消固定操作列，防止窄屏覆盖数据

- 列表筛选和总数统一由后端计算，不再对当前页重复过滤
- 列表、详情、编辑和 SSH 资源请求使用代际守卫，关闭详情/编辑或退出后迟到响应不回填
- 刷新与筛选清理旧选择；批量确认固定打开时的目标，不会因后续选择变化而操作其他任务
- 批量请求逐项计算结果，部分成功时明确展示成功与失败数量；确认前及取消不写 API
- 提交锁在异步表单校验前取得，防止双击；取消重开后的旧校验不能提交新表单
- 新任务默认重投 3 次，已有任务的显式 0 原样保留。提示说明该预算包含失败与崩溃恢复，0 不自动重投

验证：8 项 Vitest 专项、web-antd 类型检查通过；设计机械扫描为零项。实际浏览器视觉、移动端点击与最终全仓构建由统一页面验收继续补充，不将 composable 测试等同浏览器验收
