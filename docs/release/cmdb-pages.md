# 资源管理页面阶段变更

云账户、云资源、本地资源和服务树使用统一 OpsPage。页头主操作、查询条件和摘要分区由共享组件维护；模块公共样式使用控制台 token，移除摘要投影、悬浮位移及侧边粗装饰。窄屏筛选可换行，取消固定表格列，详情抽屉最大宽度不超过视口

- 查询返回与总数沿用真实服务端结果，摘要明确区分匹配总量和本页数量
- 列表与详情请求增加代际保护，旧查询、关闭详情和卸载后的迟到响应不再覆盖新上下文
- 列表失败清空旧结果并提供明确错误和重试，详情失败不将列表缓存冒充详情
- 服务树搜索命中子节点时保留祖先路径，统计覆盖所有当前可见层级，并去重同一节点
- 修复本地资源页缺失图标导入，保留原业务操作与现有厂商能力边界

验证：12项真实Ant Design组件行为测试覆盖四页的失败恢复、查询乱序和创建/同步取消零写入；3项树处理测试通过。含本批源码的全仓60文件451项单测、类型检查及11项构建任务通过。机械检查发现的4处历史粗侧边界已一次收敛为1px语义边界

仍需验收：实际浏览器明暗与390px，以及后续完整CMDB创建/编辑/绑定流程。静态审查发现云账户前端仍使用单region旧字段、后端要求regions数组，正在后续契约阶段修复，不能据此记录云账户创建已通过。SSH两页将按显式PTY协议单独升级；本阶段不冒充真实SSH或真实云调用验收
