# 表单与流程设计器交付记录

两页沿用 DESIGN.md 的 Instrument、OpsPage 和现有 Ant Design Vue 控件，保留九种表单字段、字段配置/排序、JSON 导入导出、预览、流程基本信息/可视化/JSON 三种编辑模式。没有重写设计器，没有改共享组件、全局 CSS、清单或 API 文件。

## 行为变更

- 主操作移入 OpsPage actions；使用语义色和统一边界、间距，移除卡片投影、悬浮位移和预览入场动画。窄屏元数据单列、工具栏换行，正文自然滚动，深色 JSON、字段配置与流程步骤保持可读
- 两页按真实创建 API 保存，新建返回空结果也视为成功；草稿/已发布状态仍为数值 1/2，表单是否模板与流程是否默认仍用 1/2，不推测新 ID、编辑或发布端点。字段必填仍为实际 0/1，未采用其他模块漂移的常量
- 提交期间防重复写、冻结输入并发送独立快照，错误保留设计并展示可重试状态；卸载使异步响应和定时器失效，不让迟到结果覆盖新操作
- 表单删除后新增同类字段仍保持名称唯一；保存与导入检查字段名称/标签/类型及选项结构，导入文件上限 1MiB。清空字段增加明确确认，取消保留设计；预览明确为本地校验，不再假报创建或提交工单
- 分类搜索使用请求代际，关闭时取消防抖并忽略迟到响应，失败可重试；分类选择采用明确的键盘可达按钮，不再打开一个空下拉层后另弹选择窗
- 流程同毫秒新增仍生成唯一 ID，删除前序步骤保留当前选中对象；切换步骤和搜索用户不会被旧请求覆盖。已发布表单/分类加载失败显式提示并可重试
- JSON 修改必须显式应用到可视化后保存；损坏结构不污染图。校验开始/结束、步骤 ID、名称和连接，并保留原有非结束步骤需要后续连接的检查。预览只显示图，不执行审批、通知或任何外部动作

## 实际合同与验证

Go 的表单与流程创建均返回空成功结果；关联表单列表使用 `page/size/status=2`。流程连接真正持久化的合同为 `from/to`，空 `actions/assignee_ids` 会按 Go `omitempty` 省略，`assignee_type` 可回传空字符串。浏览器读回按这些真实字段核对，不添加猜测兼容层。

原实现的两组 4 项真实 Ant Design Vue 控件回归全部失败；修复后扩为 10 项通过：表单并发保存/失败保留、唯一字段名、清空取消/本地预览、分类乱序、九种字段真实预览，以及流程提交、唯一步骤/删除选择、JSON 显式应用、加载失败恢复和用户选择乱序。未 mock 设计器内部方法，HTTP 边界使用隔离替身。

真实本地 Chrome 使用私有测试管理员和唯一 nonce，仅做本地 DB 设计 CRUD：编辑字段名称与标签、表单本地预览校验、发布表单后读回 schema、关联该表单、应用开始→结束 JSON、流程预览与取消、发布流程后读回步骤和连接。没有创建真实工单，也没有触发通知、云验证或同步。清理遵守已发布流程禁止直接删除的规则，仅将自有流程归档为 3 后删除，再删自有表单，并断言两类 active 列表均不再有该 nonce。

本专项禁用浏览器 trace/自动失败截图，不输出密码、token、认证响应或完整业务配置；人工视觉截图只含自有设计数据，保存在忽略目录。为隔离其他代理并行源码写入带来的 HMR 整页重载，独占 5778 验收服务关闭 HMR/watch；没有修改项目开发配置。应用 typecheck 通过，机械检查无发现；桌面浅色/390px 深色按两轮检查与确认。
