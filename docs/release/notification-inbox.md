# 工单站内消息界面

顶部消息中心读取当前登录用户的站内历史和未读数，支持分页、仅看未读、单条已读、确认删除和全部已读。读取失败时展示错误或未知状态，不将失败伪装为空消息或零未读；切换账户或撤销权限时清除内容并丢弃迟到响应，同账户令牌刷新不会解开正在执行操作的锁。

工单通知配置可选择站内渠道和创建人、处理人、系统用户、角色或部门，站内渠道不使用外部地址试发。消息列表和各操作分别检查网关返回的方法与路径权限，普通角色需由管理员显式授权；请求和错误不回显消息正文。后端升级及消息去重、保留策略见 Go 仓库的站内消息合同。

本阶段使用隔离替身和本地浏览器验证，无真实外发；桌面及 390px 布局均经过检查。
