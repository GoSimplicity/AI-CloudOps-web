# 第十五阶段：工单实例与完整界面流程

日期：2026-10-23

## 变更日志

- 工单实例采用 OpsPage，保留创建、模板创建、筛选、分页、导出、详情和流程处理；手机四摘要为两列，详情与步骤卡片统一主题变量及圆角
- 服务端匹配总数与本页待处理/处理中/完成分别标注，删除每次查询额外发出的四次全局计数与不准确的本页回退；读取失败显示未知、清空旧行并提供重试
- 列表、详情、编辑与选择器分别验证请求顺序及弹窗代际；迟到详情不能覆盖下一工单或新建表单，关闭后不会被旧元数据恢复。当前步骤和可用操作读取失败可手动重试，不保留脱离工单的后台重试定时器
- 模板读取 items，模板限定启用、流程限定已发布；流程/用户滚动加载真正请求下一页，避免第一页重复追加。模板默认表单值保留，标题长度对齐 Go 的 1–200 字符
- 普通编辑不写处理人或状态，处理人交给独立分配入口；步骤审批按服务端 available actions 授权，不再因实例 assignee_id 为空而隐藏合法审批。写入操作阻止处理中重复提交
- 实例通知发送记录增加真实入口、分页和错误重试，与通知配置页共用数字状态映射；通知详情使用文本 VNode 展示，不把拼接 HTML 当作内容
