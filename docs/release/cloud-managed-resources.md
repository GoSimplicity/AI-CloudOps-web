# 托管资源入口

资源页提供阿里云 RDS、传统 CLB 与缓存的独立列表、详情及指定 ID 增量同步。账户、地域、类型和方法级权限分别检查，未知结果或审计不可用时保留核对提示并阻止重复同步。历史核对不完整时不能同步；不支持的云厂商和资源类型明确说明。

已有历史记录可通过独立精确权限的人工核对接口保存操作人、理由和核对时间，界面保留原结果并重新读取持久记录。新请求携带稳定操作ID，可按操作读取与核对缺失记录；旧版未关联ID的本地标记继续阻断，不能凭空关联到新ID。实际厂商账号与生产环境未访问。

组件及原计算资源合同测试通过，全应用类型检查通过；请求层固定错误提示不回显上游资源内容。

人工核对表单要求先核对实际资源并填写10至1000字依据；提交失败或未读回审计记录时不允许在当前对话框直接重复提交。只有明确关联同一历史ID的本地阻断标记，才会在读到有效持久核对记录后解除；普通 pending 标记不会因核对其他历史被清除。身份变化立即移除旧表单并清空内容，令牌刷新保持在途锁。

本阶段25项托管资源组件测试和应用类型检查通过；本地Chrome全拦截替身验证桌面/390px模态框和核对提交，无外部云访问。

## 稳定操作与刷新恢复

新同步在发送前生成UUID，并将当前用户/账户/地域/类型下的有界资源ID和操作ID保存为恢复指针；响应必须回传匹配ID、有效计数和一致状态。缺少操作查询权限或无法保存指针时不会提交，不回退到无ID调用。指针包含基础设施标识而不含云密钥，仍需保护浏览器访问。

关闭或刷新后只能显式查询同一操作，不能把未确认请求自动变成新的同步。读取结果要匹配操作ID、范围和资源清单；确认持久结果或核对记录后还会重新核对同步历史，再移除对应标记。人工处置提交后必须再次GET读回有效审计，POST响应本身不足以解锁；失败时当前对话框禁止重复提交。

停用账户和地域现在可查询与记录核对，同步仍保持禁用，不需要临时启用。不同用户切换立即清空视图并丢弃迟到响应，同用户令牌刷新保持操作锁。旧版pending/history标记不能推断成任意新ID；已有历史的旧标记沿独立历史核对流程，无法关联的旧标记仍需停止旧客户端并进行有审计的迁移处理。

浏览器指针不提供全局互斥，服务端全范围未确认操作列表与跨标签页门禁仍需继续完善，不能仅靠清除localStorage绕过不确定状态。72项相关组件/合同回归、应用类型检查及桌面/390px全拦截模拟浏览器通过；未连接真实云或生产环境。

## 操作列表与超管核对界面

页面按独立GET权限自动读取当前范围的有界操作列表，默认本人、仅未确认，可分页；范围是否允许同步取服务端scope_blocked汇总，不能凭本人列表为空推断全范围安全。列表或汇总读取失败时禁用同步。只读审计视图保留原状态、实际核对人、依据和原结果；缺少原结果的墓碑明确说明不代表同步成功。

可信超管可显式勾选所有用户并选择目标操作，查询和核对均携带明确owner_id。组件与表格按所属用户和UUID共同区分；对其他用户的核对回执只刷新该范围，不清除本人的同UUID指针。模态框同时显示操作所属用户、当前操作者、范围和资源ID。权限或用户变化立即清除旧选择并拒绝迟到记录。

旧操作若没有资源快照，须手工输入原ID并由服务端校验原请求摘要，不猜测关联；旧无operation_id浏览器标记仍需单独迁移，已删除范围的归档核对也未在此入口支持。

本阶段86项相关组件/合同回归、应用类型检查和桌面/390px全拦截模拟浏览器通过，覆盖分页、跨用户同UUID、普通用户越权拒绝、超管撤权和只读审计展示。没有连接真实云或生产环境。
