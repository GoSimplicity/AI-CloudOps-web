# 云资源分页与同步契约

沿用现有 OpsPage、Instrument token、路由、匹配总数/本页统计及列表和详情的代际保护。普通 `/tree/cloud/list` 请求 `page/size`，仅节点专用 `/tree/cloud/:id/node` 使用 `page/page_size`。API 类型明确两种分页，不再把普通列表页大小静默交给后端默认值。

同步读取账户详情中的本地授权地域，发送数值 `cloud_account_region_ids[]`，不再发送被 Go 忽略的字符串 `regions`。空集合表示当前账户全部已启用地域；显式选择只允许当前新鲜详情中的已启用记录 ID，最多 100 项。切换账户清空原选择，迟到响应、关闭及卸载均失效。账户列表或地域加载失败可原地重试，失败期间不能同步，也不误报必须创建账户。

当前云工厂实际实现阿里云 ECS：同步账户仅提供已启用阿里云，资源类型固定数值 `[1]`，其他类型展示为未开放；其他存量云平台和资源类型可查看，不开放修改、绑定、状态或终端操作。默认增量同步，保留全量显式选项，并说明全量会移除所选地域中云端已不存在的本地 ECS 记录。账户及地域选择只读本地 DB，不查询云地域目录；只有“开始同步”才调用同步接口。

提交使用独立快照，处理中冻结输入及取消、防重复确认，卸载忽略结果。响应必须包含有效非负整数统计，不再用 `|| 0` 将未知响应伪装成成功；`failed_count > 0` 显示部分完成，失败保留选择并提示检查历史。同步历史区分进行中、部分完成、成功与失败。导出遵守 DESIGN，仅当前页；删除全仓引用审查确认不被真实路由消费的 legacy 三文件。

已执行验证：

- 原 4 项真实 Ant Design Vue 控件回归全部失败，修复后扩为 8 项全部通过：普通与节点分页、数值地域/ECS/增量 payload、账户切换乱序与取消、部分失败/未知响应、地域失败重试和停用排除、重复提交、非阿里云及非 ECS 只读、账户加载失败恢复
- 既有 CMDB 12 项列表失败恢复、乱序响应、取消回归通过，应用 typecheck 通过
- 本地真实 Chrome 源码 UI + localhost18080 隔离管理员：创建唯一 nonce 假凭据双地域账户，读取真实本地地域 ID、选择地域、确认 ECS/增量默认，取消后零 verify/sync/available-regions 请求；桌面浅色和 390px 深色截图无页面横向溢出，取消可点击，finally 精确删除自有账户/地域
- Impeccable 机械检查无发现，截图在忽略目录；专项关闭 trace 与自动截图，不输出管理员密码、认证响应或云凭据

没有调用任何云 SDK，也没有连接真实云；实际云同步成功率和厂商权限不属于本地验收结果。浏览器专项仅验证确认前的真实读取与取消，提交结果和异常交互由真实 Antd 控件配合隔离 HTTP 替身验证。
